# Sunday Intelligence Mode

Sunday is a protected maintenance and intelligence window.

## Hard prohibition

No marketing execution on Sunday:

- no social publishing
- no comments/replies
- no DMs/outreach
- no follows/likes used for growth
- no paid ad launch or spend
- no directory submissions

## Allowed work

### Product reality check

Visit and inspect the current public production sites for Keanso and AI-Bid. Reconcile important public claims against current implementation/documentation where accessible.

### Market intelligence

Collect relevant, current information about target audiences, competitors, product launches, pricing/positioning changes, recurring pain points, useful discussions, and channel opportunities.

### Change detection

Compare current findings with the previous knowledge snapshot. Record only meaningful changes with source, timestamp, confidence, and affected brand.

### Analytics

Process the previous week's performance and identify which channels, topics, formats, and campaigns produced meaningful outcomes.

### System audit

Check scheduled-job results, integration health, rate-limit/errors, duplicate-content risks, attribution gaps, and stale configuration.

### Strategy

Produce the next week's prioritized experiments and campaign briefs. Strategy output becomes eligible for execution when Monday begins.

## Output contract

The Sunday run should produce:

1. product-change report
2. market/competitor-change report
3. performance report
4. system-health report
5. next-week strategy
6. unresolved questions requiring evidence

No Sunday output should directly publish or contact an external audience.
