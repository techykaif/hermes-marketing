# Marketing Drafts

Drafts are the handoff between Hermes research/planning and any external publishing system.

Each draft should include:

- `draft_id`
- product
- channel
- campaign_id
- objective
- evidence references
- content
- proposed CTA/link
- UTM parameters
- risk class
- approval status
- created_at
- expires_at when time-sensitive

Drafts are not publications. A draft must pass the channel policy and approval boundary before an external action is attempted.
